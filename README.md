# NLP Exam Study App

Interactive study tool for AIPI 540 (Deep Learning Applications) at Duke MENG AI.

**[Live Demo](https://lindsaygross.github.io/NLP_overview/)**

## Features

- **Practice Questions** — 60+ scenario-based quiz questions covering application, debugging, mechanism explanation, comparison, and system design
- **Concept Explorer** — Interactive visual breakdowns of 17 NLP topics with live demos (preprocessing pipeline, TF-IDF calculator, LSTM gate walkthrough, self-attention visualization, transformer architecture)
- **Connections Map** — Visual graph showing how NLP concepts relate and evolve
- **Quick Reference** — Printable cheat sheet cards for every topic
- **Dark Mode** — Toggle between light and dark themes
- **Progress Tracking** — Tracks which concepts you've studied and quiz performance by topic

## Topics Covered

1. Text Pre-processing Pipeline
2. Bag of Words & TF-IDF
3. N-grams
4. Hidden Markov Models
5. Word Embeddings & Word2Vec
6. RNNs
7. LSTMs (High Priority)
8. GRUs
9. Self-Attention (Highest Priority)
10. Scaled Dot-Product Attention
11. Multi-Head Attention
12. Cross-Attention
13. Transformer Architecture (Highest Priority)
14. Transformer Types
15. NLP Implementation Practices
16. NLP Applications
17. Advanced Topics (RAG, CLIP, MoE)

## Tech Stack

- React 19 + Vite
- Tailwind CSS v4
- No backend — all content hardcoded
- Deployed via GitHub Pages
